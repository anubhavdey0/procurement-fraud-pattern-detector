# Sample output

`assam-report.html` is the report written by `bidscreen screen assam`. Download it and open it in a browser. It is one self-contained file: no scripts or fonts are loaded from anywhere.

Every firm, tender and buyer in it appears under a label. Dates are shown to the month. The key that maps labels to names was generated on the machine that produced the file and is not in this repository, so the labels cannot be reversed from here.

The numbers in `../validation/` are aggregate scores from `bidscreen validate`. They contain no tender-level data.

This file and the figures in `../figures/` contain information from the Assam Public Procurement Data, made available by CivicDataLab under the Open Database License (ODbL).

Everything in the report is a lead for review. None of it is a finding.
